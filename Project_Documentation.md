# Project Documentation

## 1. Project Title
**Student Performance Analytics System**

## 2. Objective
The objective of this project is to analyze student academic performance using Python. The program reads student data from a CSV file and calculates useful results such as total marks, average marks, grades, pass/fail status, subject performance and top performers.

## 3. Technologies Used
- Python
- NumPy
- Pandas
- CSV file

## 4. Dataset Description
The dataset contains 20 student records. Important columns are:
- Student_ID
- Name
- Department
- Python_Marks
- Maths_Marks
- Statistics_Marks
- Attendance

## 5. Implementation
1. Student data is stored in `students.csv`.
2. Pandas `read_csv()` is used to load the dataset.
3. A loop goes through every student record.
4. NumPy is used to calculate total and average marks.
5. Functions are used for grade calculation, pass/fail checking and different analyses.
6. Pandas operations such as `nlargest()`, `value_counts()` and `groupby()` are used for analysis.
7. A menu-driven program lets the user select the required output.

## 6. Key Features
- Total marks calculation
- Average marks calculation
- Grade assignment
- Pass/fail identification
- Highest and lowest performer
- Overall class average
- Subject-wise performance
- Top 5 performers
- Department-wise average
- Menu-driven output

## 8. Final Outcome
The project successfully analyzes student performance from a CSV dataset and displays understandable results. It uses basic Python concepts together with NumPy and Pandas, without using machine learning.

## 9. Challenges & Learning
While making this project, the main challenge was deciding where to use normal Python, NumPy and Pandas properly. I learned that functions make code reusable, loops are useful when processing records one by one, NumPy is useful for numerical calculations, and Pandas makes tabular data analysis easier.
